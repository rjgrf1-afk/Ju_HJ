개인정보처리방침

눈썰미 연구소 업로더 · 시행일 2026년 10월 20일

"눈썰미 연구소 업로더"(이하 "앱")는 유튜브 채널 눈썰미 연구소의 운영자가 자기 채널에 직접 만든 쇼츠 영상을 예약 업로드하고, 그 채널의 통계를 확인하기 위해 쓰는 개인용 도구입니다. 운영자 본인 외의 사용자는 없습니다.

접근하는 정보

Google OAuth로 운영자가 허락한 다음 권한만 사용합니다.

  • youtube.upload: 운영자 채널에 영상을 업로드하고 제목, 설명, 공개 시각을 설정
  • youtube.readonly: 운영자 채널의 영상 목록과 공개 정보 조회
  • yt-analytics.readonly: 운영자 채널의 조회수, 시청 지속률 등 통계 조회

정보의 이용과 보관

  • 위 정보는 영상 업로드와 채널 운영 개선에만 씁니다.
  • 인증 토큰은 운영자의 작업 환경에 비밀 값으로만 보관하며, 공개 저장소나 다른 곳에 기록하지 않습니다.
  • 어떤 정보도 판매하거나 제3자에게 제공하지 않으며, 광고에 쓰지 않습니다.
  • 다른 사용자나 시청자의 개인정보는 수집하지 않습니다.

데이터 삭제

  • 앱은 채널 통계를 별도 데이터베이스에 저장하지 않으며, 업무 판단에 쓴 통계 기록은 받은 날로부터 30일 안에 삭제하거나 새로 고칩니다.
  • 권한을 철회하거나 앱 사용을 중단하면, 운영자의 작업 환경에 저장된 인증 토큰과 남아 있는 API 데이터를 7일 안에 삭제합니다.
  • 삭제 요청은 아래 '문의' 경로로 할 수 있습니다.

권한 철회

언제든지 Google 계정의 서드파티 액세스 페이지에서 앱의 접근 권한을 해제할 수 있습니다. 해제하면 앱은 더 이상 채널에 접근할 수 없습니다.

Google API 서비스 정책 준수

앱이 Google API로 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 앱은 YouTube API 서비스를 사용하며, 이용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

English summary

"눈썰미 연구소 업로더" (Nunsseulmi Lab Uploader) is a private tool used only by the owner of the YouTube channel @nunsseulmi_lab to upload and schedule the owner's own Shorts and to read the owner's own channel statistics. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

  • Data accessed: upload access, the owner's channel and video list, and the owner's YouTube Analytics reports (scopes youtube.upload, youtube.readonly, yt-analytics.readonly).
  • Use: only to upload the owner's videos and improve the owner's content. No data is sold, shared with third parties, or used for advertising. No viewer or third-party channel data is collected.
  • Storage: the OAuth refresh token is kept only as a private environment variable of the owner's workspace.
  • Deletion: statistics used for decisions are deleted or refreshed within 30 days; tokens and any remaining API data are deleted within 7 days after access is revoked or the tool is no longer used.
  • Revoke access at any time: myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
