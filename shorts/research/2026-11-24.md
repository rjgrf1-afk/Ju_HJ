# 오후 연구 2026-11-24: 착시 편에 쓸 수 있는 소재 — 직접 그릴 수 있는 착시 찾기

착시 편(수·토)은 두 편 모두 낮 편의 약 2배가 나왔다. 하지만 같은 그림을 반복하면 식는다(11/16 연구: 일곱시오분 240만 → 4.7만, 물건을 바꾸자 21만으로 회복). 내일 3호부터 쓸 수 있도록, 요즘 잘되는 착시 쇼츠 중 **남의 그림 없이 코드로 직접 만들 수 있는 것**을 골랐다.
방법: YouTube Data API — 검색 3회(일본 '錯視 脳トレ', 미국 'optical illusion test', 한국 '착시 테스트'; 9/15 이후 짧은 영상 조회순).

## 2. 우리가 직접 만들 수 있는 것

| 소재 | 만드는 법 | 쉬움 |
|---|---|---|
| **화살표 회전** | 납작한 화살표(다각형)를 세로축으로 돌려 그림자만 | 쉬움 |
| **흩어진 막대 → 모양** | 3D 공간에 막대를 흩어 두되, 한 각도에서 보면 별·하트·숫자가 되게 배치하고 돌린다 | 보통 |
| **동물 그림자(오리·고양이)** | 지금처럼 공을 이어 몸·머리·부리 모양을 만들어 돌린다 | 보통 |
| **클로버·바람개비 회전** | 평면 도형 회전, 방향 착시 | 쉬움 |
| 흑백 원반 색 착시(Benham 팽이) | 흑백 무늬 원반을 빠르게 돌림 — 1894년부터 알려진 착시 | 보통(쇼츠 압축으로 효과가 약해질 수 있음) |

- 모두 남의 그림·캐릭터 없이 수식으로 그릴 수 있다. 피카츄·스파이더맨 같은 남의 캐릭터 착시는 쓰지 않는다.

## 3. 우리 채널에 적용할 아이디어 (11/28 착시 편 판정 때 함께 결정)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **착시 편 소재를 돌려 쓰기: 사람 → 화살표 → 흩어진 막대 → 동물** — 같은 그림자 반복을 피한다. 근거: 1절(일본 상위 채널은 매번 다른 물건, 일곱시오분은 물건 바꾸자 회복). 예상 효과: 착시 편끼리 겹침 방지('진정성 없는 콘텐츠' 기준), 조회 유지. 쉬움~보통.
2. **'흩어진 막대가 한순간 모양이 되는' 착시를 새 형식으로** — 161만 회 소재. 막대가 돌다가 한 각도에서 숫자(예: '7')가 되고 '무슨 숫자가 보였나요? 댓글로'로 끝낸다 — 퀴즈와 착시를 합친 형식이라 우리 채널 이름(눈썰미)과도 맞다. 보통.
3. **일본어 제목은 '○%만 거꾸로 돌릴 수 있다'형** — 11/16 연구 아이디어 2와 같은 결론, 근거 더 쌓임. 쉬움.
