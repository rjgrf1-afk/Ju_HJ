# 오후 연구 2026-11-22: 단계형 퍼즐 채널은 틀을 어떻게 바꾸나 (저녁 정체 대응 재료)

저녁 3단계 쇼츠가 3일 연속 첫 노출에서 막혔다(11/19~11/21). 같은 날 낮 편은 정상이고, 저녁 편의 넘기지 않고 본 비율은 오히려 높다(11/21 연구). 내일 주간 보고서에서 저녁 형식을 바꾸기 전에, 비슷한 단계형 퍼즐 채널이 틀을 어떻게 돌려 쓰는지 봤다.
방법: YouTube Data API — 검색 2회(한국 '1단계 2단계 3단계', 미국 'level 1 level 2 level 3', 10/1 이후 짧은 영상 조회순), 상위 채널 4곳 최근 20편.

- 정체는 큰 채널도 20편 중 1~3편 꼴(5~15%)로 생긴다. 우리도 저녁 쇼츠 34편 중 정체 4편이면 비슷한 수준이었는데, **3일 연속은 이례적**이다.

## 2. 눈에 띈 채널: Sharp Eye Test

- 구독 488명인데 최근 20편 중앙값 4,014회(우리 약 1,000회의 4배). 하루 4~5편.
- **편마다 형식이 다르다.** 같은 날 올린 5편이 모두 다른 틀이다:
  - '3 Odd Ones Hiding: 📄🚺🚯' — 판 하나에 다른 것 3개 숨기기
  - 'Find the 4 Faces Looking Down' — 아래를 보는 얼굴 4개 찾기
  - '4 of These Are Flipped. Find Them All' — 뒤집힌 것 4개 모두 찾기
  - 'Find 🐧, Then 🔠, Then 🕛: Easy, Hard, BRUTAL' — 우리와 같은 3단계
  - 'Find the 4 🫵 Pointing With the Other Hand' — 다른 손으로 가리키는 것 4개
- 길이 6~19초. **'여러 개 다 찾기'**가 주력이고, 3단계는 여러 틀 중 하나일 뿐이다.
- Ravi X Jone도 '숨은 물건 1~4단계', 로고 맞히기, 숨은 기기 찾기를 섞는다. 3Gamerz는 문제마다 길이가 16~39초로 다르다.

## 3. 핵심

- 우리 저녁 쇼츠는 34편이 모두 '1단계 5x5 → 2단계 7x7 → 3단계 8x8 → 보너스 → 아웃트로' 같은 틀, 같은 길이(25.6초)다. 잘되는 단계형 채널은 **틀과 길이 자체를 편마다 바꾼다.** 같은 틀이 매일 반복되면 유튜브가 '비슷한 영상'으로 묶어 첫 시험 노출을 줄인다는 11/7 가설과 맞는다.

## 4. 우리 채널에 적용할 아이디어 (내일 주간 보고서에서 결정)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **저녁 형식을 3~4가지로 돌려 쓰기** — 요일마다 틀 자체를 바꾼다:
   - (가) 지금의 3단계(쉬움·보통·극악)
   - (나) **'다른 것 3개 다 찾기'** — 판 하나(8x8)에 다른 그림 3개, 12초 + 정답 공개. 댓글에 'B2 E5 G7'처럼 세 칸.
   - (다) **빠른 5단계** — 단계마다 3초, 5x5부터 9x9까지(약 20초)
   - (라) 3단계 + 보너스 없이 짧게(18초)
   근거: 2절(Sharp Eye Test 편마다 다른 틀, 중앙값 우리 4배). 예상 효과: 저녁 정체 감소, 편당 조회 상승. 보통(그리기·정답 공개 코드는 있음).
2. **길이도 날마다 다르게** — 형식마다 12~26초로 자연스럽게 달라진다. 쉬움(1번에 포함).
3. **'다 찾기' 형식은 정답 칸 이름표와 잘 맞는다** — 칸 이름 세 개를 댓글로 쓰게 하면 댓글 실험(11/27 판정)과도 이어진다. 쉬움.
