# 오후 연구 2026-11-15: 인도네시아어·힌디어 '다른 숫자 찾기' 시장

11/12에 스페인어·포르투갈어를 봤다. 오늘은 우리 번역 제목의 나머지 두 언어, 인도네시아어와 힌디어 쪽에서 '다른 숫자·이모지 찾기'가 어떻게 검색되고 누가 잡고 있는지 봤다. 숫자 문제는 우리 낮 쇼츠의 절반이고 해외 조회가 나는 유형이다(11/9).
방법: YouTube Data API — 검색 4회(인도네시아 2·인도 2, 10/15 이후 짧은 영상, 조회순), 영상·채널 정보.

## 2. 핵심

- **인도네시아어 숫자 퍼즐은 Quiz Catch 한 채널이 독차지**하고 있다(개설 46일, 구독 1.94만). 경쟁자가 없다는 뜻이기도 하고, 인도네시아 시청자가 이 형식을 좋아한다는 증거이기도 하다.
- **인도 시청자는 힌디어 글자로 검색하지 않는다.** 힌디어 제목 영상은 조회가 거의 없고, 잘되는 인도 영상은 모두 **영어 제목**('find the odd number', 'find the odd emoji')이다. 우리 힌디어 번역 제목은 인도 시청자에게 거의 닿지 않을 가능성이 크다.
- 인도 쪽 '다른 숫자' 영상은 **댓글이 아주 많다**(31만 회에 389개 = 1,000회당 1.25). 숫자 하나로 답할 수 있는 형식이라(11/13 연구와 같은 이치) 댓글이 쉽다.
- 인도·인도네시아·케냐 모두 쇼츠 1,000회당 수익은 낮은 편이다(나라별 쇼츠 수익 추정: [FluxNote](https://fluxnote.io/guides/youtube-shorts-rpm-by-country)). 수익보다 조회·구독(수익 창출 조건) 쪽에 보탬이 되는 시장이다(11/12 연구와 같은 결론).

## 3. 우리 제목 상태

- 영어: 이모지·좌우 반전은 'Find the Odd Emoji:', 색깔은 'Find the Odd Color:'로 이미 실제 검색어에 맞췄지만, **숫자는 'Find the Odd One Out:'** 이다. 인도에서 실제로 쓰는 말은 'find the odd number'.
- 인도네시아어: 숫자도 'Cari yang beda:' — 실제 검색어는 'cari angka berbeda'.
- 힌디어: 'अलग वाला ढूंढो:' — 이 말로 찾는 사람이 거의 없다.

## 4. 우리 채널에 적용할 아이디어 (월요일 주간 보고서 재료)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **숫자 문제 영어 제목 앞머리를 'Find the Odd Number:'로** — 이모지·색깔과 같은 방식(make_short·make_one의 영어 prefixes에 number 추가). 근거: 1절 인도 검색 상위 제목. 예상 효과: 영어권·인도 검색 유입 조금. 쉬움(한 줄).
2. **숫자 문제 인도네시아어 앞머리를 'Cari angka berbeda:'로** — 실제 검색어이고 지금 Quiz Catch 혼자 차지한 말이다. 근거: 1절. 쉬움(한 줄).
3. **힌디어 번역은 영어 제목으로 바꾸거나 빼기 검토** — 인도 사용자는 대부분 영어 제목을 본다. 힌디어 번역을 영어와 같게 두면 힌디어 화면 사용자에게도 실제 검색어가 보인다. 근거: 1절(힌디어 검색 거의 0). 쉬움. 위험: 거의 없음(힌디어 번역 효과가 원래 작음).
