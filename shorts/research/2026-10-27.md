# 오후 연구 2026-10-27: 외국인 시청자를 들이는 법 ① 제목·설명 다국어화

채널 주인이 어제 정한 방향('외국인도 알고리즘에 빠질 수 있게, 글로벌하게 가자')에 맞춘 첫 연구다. 우리 채널의 지금 상태는 시청자 100% 한국, 35~54세가 약 87%다(10/26 통계). 오늘은 해외에서 잘되는 퍼즐 쇼츠 채널이 **제목과 설명을 어떻게 쓰는지**를 봤다.

## 1. 다른 채널 살펴보기: 나라별 검색

YouTube Data API 검색(search.list)에 `regionCode`(나라)와 `relevanceLanguage`(언어)를 넣어 미국·브라질·멕시코·인도·인도네시아에서 '다른 그림 찾기 / odd one out' 계열 쇼츠를 찾았다. 상위 영상은 `videos.list`의 `localizations`(언어별 제목·설명)까지 확인했다.

**공통점**
- 화면에 글자가 거의 없거나 짧다. 퍼즐 자체가 말 없이 통한다.
- 제목·설명만 나라별 언어로 바꾼다. 시청자는 자기 언어로 된 제목을 본다. 같은 영상이 나라마다 다른 제목으로 노출되는 셈이다.
- 제목 앞에 이모지 2~3개를 붙인다. 이모지는 어느 나라에서나 읽힌다.

## 2. 오늘의 주제: 제목·설명 다국어화는 어떻게 하나

- **유튜브가 제목을 자동으로 번역해 주지는 않는다.** 공식 기능으로 찾은 건 '직접 추가'뿐이다. 스튜디오 → 자막 → 언어 추가 → '제목 및 설명'에 언어마다 직접 입력한다. ([YouTube 고객센터](https://support.google.com/youtube/answer/6289575))
- **API로 올릴 때 한 번에 넣을 수 있다.** `videos.insert`에서 `snippet.defaultLanguage`와 `localizations.<언어코드>.title / description`을 함께 보내면 된다. 지금 쓰는 `youtube.upload` 권한으로 된다. ([videos.insert 문서](https://developers.google.com/youtube/v3/docs/videos/insert))
- 외부 번역 도구(CreatorLingo 같은 크롬 확장 등)도 있지만, 우리는 제목이 짧아서 번역을 직접 만들어 넣으면 된다. 돈이 드는 도구는 필요 없다.
  - 참고: [bemultilingual](https://www.bemultilingual.ca/blog/how-to-translate-language-on-youtube), [air.io](https://air.io/youtube-hacks/how-to-localize-and-translate-youtube-metadata)

**우리 채널의 걸림돌**
- 화면 문구('이거 찾을 수 있어요?', '1단계' 등)가 한국어다. 제목만 바꿔도 들어오기는 하겠지만, 화면 글자를 못 읽으면 빨리 넘길 수 있다.
- 지금은 자동 업로드를 쓰지 않고(감사 승인 전) 채널 주인이 손으로 올린다. 그래서 언어별 제목을 넣으려면 스튜디오에서 한 번 더 입력해야 한다.

## 3. 우리 채널에 적용할 아이디어

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **metadata.json에 언어별 제목·설명을 같이 만든다.** 우선 6개 언어: 영어, 일본어, 스페인어, 포르투갈어(브라질), 힌디어, 인도네시아어.
   - 손 업로드 기간에는 복사해서 붙여 넣기 쉬운 형태로 함께 보낸다.
   - 근거: 해외 상위 퍼즐 채널이 모두 이렇게 한다. 비용 0원.
   - 만들기: **쉬움**.
2. **영상 화면 문구를 '말 없이 통하게' 바꾼다.** 단계 표시를 숫자·이모지 위주(예: '1/3', '🔥🔥🔥')로 줄이고, 시작 문구에 짧은 영어를 같이 단다.
   - 위험: 한국 시청자에게 어색할 수 있다. 하루 이틀 시험해 보고 평균 시청률을 비교한다.
   - 만들기: **보통**.

### 권한이 필요한 것
3. **업로드 스크립트(upload.py)에 `localizations`를 넣는다.** 감사 승인 후 자동 업로드를 켤 때 언어별 제목이 같이 올라가게 한다.
   - 조건: 채널 주인이 'YouTube API 감사(audit) 승인됨'이라고 말한 뒤에만 쓴다.
