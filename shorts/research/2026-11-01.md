# 오후 연구 2026-11-01: '넌센스 퀴즈' 느낌을 외국인도 풀 수 있게 넣는 법

10/30 채널 주인 제안('약간 넌센스 퀴즈 느낌도 한번 생각해봐')을 오늘 주제로 잡았다. 10/30에 적은 걱정은 '넌센스는 대부분 한국어 말장난이라 외국인은 못 푼다'였다. 그래서 나라별로 잘되는 넌센스·수수께끼 쇼츠가 말에 기대는지, 그림·숫자에 기대는지를 봤다.
방법: YouTube Data API 검색 4회(최근 60일, 4분 이하, 조회순): '넌센스 퀴즈'(한국), 'matchstick puzzle'(미국), 'emoji riddle guess'(미국), 'なぞなぞ'(일본). 나라별 상위 9편과 그 채널을 봤다.

## 2. 핵심

- **말장난 넌센스는 그 나라 안에서만 돈다.** 한국 넌센스 상위는 사람이 나오는 콩트이고, 얼굴 없는 글자 화면은 조회는 나와도 댓글이 거의 없다(48만 회에 댓글 3개).
- **'고정관념을 깨는 숫자 문제'가 넌센스 느낌을 내면서 말이 필요 없다.** 성냥개비 하나 옮겨 식 고치기('3 + 3 = 5' → 맞는 식), '06에서 하나 옮겨 가장 큰 수 만들기' 같은 문제다. 답을 보면 '아, 그게 되네' 하는 넌센스의 재미가 있고, 댓글로 답을 다는 사람이 많다(Saro With Sasi 편당 댓글 16~60개, 비슷한 조회의 한국 글자 넌센스는 2~3개).
- **일본 '頭やわらかい(말랑한 머리)' 문제**도 같은 재미다. 12초짜리가 176만 회.

## 3. 우리 채널에 적용할 아이디어 (월요일 주간 보고서 재료)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **보너스 퀴즈에 '거꾸로 보면' 숫자 넌센스 추가** — 예: 주차장 번호 문제 '16 06 68 88 ? 98'(화면을 뒤집어 보면 86 87 88 89 90 91 → 답 87), '9 = 6?'. 3초 안에 '아!' 할 수 있고 숫자만 쓴다. 근거: 2절. 효과: 댓글('이거 뭐야ㅋㅋ'). 쉬움(quiz_pool.py에 유형 하나 추가, 답이 하나로 떨어지는 것만 골라야 함).
2. **성냥개비 식 고치기를 보너스 퀴즈로(이틀에 한 번)** — '성냥 1개를 옮겨 맞는 식으로!' 5초 + 정답 2초. 근거: Saro With Sasi(10.9만) 상위 독식, 말이 필요 없음, 해외 통함. 효과: 해외 조회·댓글. 보통(성냥 숫자 그리기, 문제마다 답이 하나뿐인지 손으로 확인 필요). 3초는 짧아 5초로 늘려야 한다.
3. **한국어 말장난 넌센스는 넣지 않는다** — 해외 0, 댓글도 적다. 꼭 한다면 커뮤니티 게시물(글) 쪽이 맞다.
