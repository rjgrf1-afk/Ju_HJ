오늘은 글로벌 주제 대신, 11/4부터 이어진 부진(11/4 저녁 정체, 11/6 영상 전부 부진, 11/7 낮 쇼츠 공개 2시간 조회 0회)을 진단했다. 해외로 넓히기 전에 국내 노출이 끊기는 원인부터 잡아야 한다.
방법: YouTube Analytics API 일별·유입 경로별 조회(10/28~11/4, 자료는 11/4까지), Data API로 영상 상태·조회.

- **낮 쇼츠도 같은 제목 방지**: 11/5에 저녁 쇼츠만 고쳤고 낮 쇼츠는 빠져 있었다. 숫자 문제 10/30과 11/4의 영어 제목이 글자 하나까지 같았다. 낮 쇼츠도 최근 14일 같은 유형 영상의 꼬리말·번역 제목을 피하게 하고, 언어마다 꼬리말을 2개 → 4개로 늘렸다(11/8 영상부터).

## 4. 우리 채널에 적용할 아이디어 (월요일 주간 보고서 재료)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **영상 틀 자체를 더 다르게** — 배경색만 바뀌고 글자 배치·문구·소리가 매일 같다. 날마다 다른 배경 무늬, 다른 효과음 세트, 문구 몇 가지를 돌려 쓰기. 근거: 2절의 채널 단위 판정 가능성. 보통.
2. **하루 2편 → 잠시 하루 1편** — 노출이 줄 때 같은 틀 영상을 계속 쏟으면 '대량 생산' 신호가 더 쌓일 수 있다. 월요일 자료(11/5~11/6 유입 경로)를 보고 정체가 이어지면 낮 쇼츠를 이틀에 한 번으로 줄이는 방안. 쉬움.
3. **11/4·11/6 멈춘 영상은 그대로 둔다** — 지우거나 다시 올리면 진짜 중복이 된다.
