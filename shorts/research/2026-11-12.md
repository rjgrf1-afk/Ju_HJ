# 오후 연구 2026-11-12: 스페인어·포르투갈어(중남미) '다른 하나 찾기' 쇼츠 시장

해외 조회는 아직 미국 1%뿐이다(11/9 연구). 우리는 10/27부터 스페인어·포르투갈어 번역 제목을 달고 있다. 오늘은 그 두 언어권에 실제로 어떤 '다른 하나 찾기' 쇼츠가 잘되고, 우리 같은 '어른용 말 없는 퍼즐'이 들어갈 자리가 있는지 봤다.
방법: YouTube Data API — 검색 4회(멕시코·스페인·브라질, 언어 es/pt, 8/12 이후 짧은 영상, 조회순), 영상·채널 정보, 상위 채널 3곳의 최근 50편.

## 1. 검색 결과 요약

| 검색어(나라) | 상위를 차지한 영상 |
|---|---|
| encuentra el diferente (멕시코) | 마인크래프트·만화 캐릭터 '다른 것 찾기'(Diander, 50초), 국기 찾기, 아이용 놀이 |
| encuentra el emoji diferente (스페인) | **인도 채널의 영어 6초 'find the odd emoji'가 1~10위 대부분** (7만~114만 회) |
| encontre o diferente (브라질) | 그림 찾기(Vnz Desenho), 단어 퀴즈(Mestre do QUIZ), 축구 선수 얼굴 찾기 |
| ache o emoji diferente (브라질) | **최고 1,786회**. '1~3단계', '1%만 찾는 3단계' 같은 우리와 비슷한 제목이 이미 있지만 모두 1천 회 안팎 |

- 스페인어로 '이모지 다른 것 찾기'를 찾으면 스페인어 영상이 아니라 **인도의 영어 영상이 나온다**. 그 언어로 만든 어른용 이모지 퍼즐이 거의 없다는 뜻이다.
- 포르투갈어 이모지 퍼즐은 만든 사람은 있지만 조회가 아주 적다(작은 채널들, 1천 회 안팎).

## 2. 눈에 띈 채널

| 채널 | 나라·언어 | 구독 | 최근 50편 | 길이 중앙값 | 조회 중앙값 | 특징 |
|---|---|---|---|---|---|---|
| **Diander** | 스페인어(중남미) | 353만 | 9/18~11/11, 하루 1편 | 52초 | **17만** | 마인크래프트 등 게임 캐릭터 '다른 것 찾기'·'맞혀 봐'. 번호 붙인 연재('ENCUENTRA el DIFERENTE 8', '12'), 제목 47가지로 매번 다름. 시청자는 아이·청소년 |
| Desafios Mentais | 브라질 | 191만 | **6일에 50편(하루 8편)** | 25초 | 3,303 | 포르투갈어·영어 섞어 대량 생산. 마리오·포코요 등 **남의 캐릭터**를 씀. 조회 급락 — '대량 생산' 위험의 실제 예 |
| Vnz Desenho | 브라질 | 47.6만 | 하루 2~3편 | 25초 | 3.1만 | 7월 개설. '다른 그림 찾기'로 시작해 지금은 생활 요령·도전 영상으로 바뀜 |

- 잘되는 두 언어권 '다른 것 찾기'는 **아이용 + 게임·만화 캐릭터**다. 캐릭터는 저작권 문제로 우리가 쓸 수 없고, 시청자층(35~54세)도 다르다.
- Desafios Mentais는 하루 8편, 남의 캐릭터, 두 언어 섞기로 구독 191만인데 최근 조회 중앙값이 3천 회다. 편수를 늘려 밀어붙이는 방식이 지금은 안 통한다는 근거로 볼 수 있다(11/7·11/8 연구의 '하루 2편 유지' 결론과 맞음).

## 3. 돈으로 따지면

- 쇼츠 1,000회당 수익(추정): 브라질 약 0.03~0.05달러, 멕시코 약 0.03~0.04달러. 두 곳 모두 '단가는 낮고 양으로 버는 시장'으로 분류된다. [AIR Media-Tech](https://air.io/en/monetization/what-rpm-can-you-expect-from-shorts-in-2025), [FluxNote](https://fluxnote.io/guides/youtube-shorts-rpm-by-country)
- 스페인 쇼츠 단가 자료는 찾지 못했다. 긴 영상 기준 광고 단가만 있다(쇼츠와 비교 불가). [FluxNote 중남미](https://fluxnote.io/guides/youtube-earnings-latin-america-2026)
- 결론: 중남미는 **수익보다 조회·구독 수를 키우는 시장**이다. 수익 창출 조건(쇼츠 조회 수)을 채우는 데는 보탬이 되지만, 1회당 수익은 한국·미국보다 낮다.

## 4. 우리 채널에 적용할 아이디어 (월요일 주간 보고서 재료)

### 바로 적용할 수 있는 것 (권한·비용 없음)
1. **스페인어 번역 제목은 이미 맞게 돼 있다** — 저녁·낮 쇼츠 모두 스페인어 제목 앞머리가 'Encuentra el diferente:'(사람들이 실제로 찾는 말)다(10/27 적용). 이 검색어의 이모지 쪽은 스페인어 영상이 거의 비어 있어 자리가 있다. 할 일: 앞으로 2주 동안 스페인어권(멕시코·스페인·아르헨티나 등) 조회가 생기는지 나라별로 지켜본다. 쉬움(daily_stats 나라별 확인).
2. **포르투갈어는 지금 그대로** — 'ache o emoji diferente'는 만든 사람이 있는데도 찾는 사람이 적다. 더 손대지 않는다. 쉬움(할 일 없음).
3. **하루 편수는 늘리지 않는다** — Desafios Mentais(하루 8편) 사례로 다시 확인. 대신 '영상마다 다르게'(소재·제목) 규칙을 유지한다.

## 5. 추가(사용자 제보): '생각만으로 회전 방향 바꾸기' 착시 쇼츠

- 채널 '일곱시오분'(한국, 2월 개설, 구독 6,030, 총 조회 4,013만). 11/3부터 매일 같은 형식: 검은 그림자가 도는데 어느 쪽으로 도는지 정해지지 않아, 마음먹은 대로 방향이 바뀌어 보이는 착시(평행 투영 그림자라 앞뒤 깊이가 없음). 17~30초, 제목은 '생각만으로 회전방향 바꾸기(난이도 ○○)'.
- 조회: 11/3 242만, 11/6 243만, 11/5 78만, 11/4 31만, 11/8 23만 → 11/10 7만, 11/11 4.7만. **처음 며칠은 폭발, 같은 걸 매일 반복하자 빠르게 식는 중.** 댓글이 많다(공개 반나절 9천 회에 36개) — '나는 반대로 보여' 식 참여.
- 우리 쪽에서 직접 만들 수 있음을 확인: 공 여러 개로 만든 사람 모양을 돌려 그림자만 그리면 같은 착시가 난다(남의 그림·영상 안 씀). 시험본 scratchpad/rot/sil.py.
- 판단 재료: 그 채널 제목·형식을 그대로 따라 하면 '베낀 영상'이 되고, 이미 식는 중이다. 쓴다면 우리 퀴즈 안의 한 단계('보너스: 몇 번 방향이 바뀌었나요?')나 주 1회 특별편 정도로.
